# AI Trading Agent (وكيل تداول بالذكاء الاصطناعي)

وكيل تداول آلي يعمل على أي منصة تدعمها مكتبة `ccxt` (Binance, Kraken, Bybit, OKX, ...).

## كيف يعمل
1. **البيانات**: شموع OHLCV من المنصة.
2. **التنبؤ**: نموذج انحدار لوجستي على مؤشرات (RSI, EMA, ATR, تقلب، عوائد) يقدّر احتمال صعود السعر.
3. **الدخول**: عند احتمال ≥ `entry_threshold` (افتراضي 0.60) وبحجم يخاطر بـ 1% فقط من الرصيد.
4. **الخروج**: وقف خسارة (ATR)، جني أرباح، نقل الوقف إلى نقطة التعادل (+الرسوم) بعد ربح أولي، ثم وقف متحرك.
5. **حماية**: حد خسارة يومي (3%) ومفتاح إيقاف عند تراجع 15%.

## التشغيل
```bash
pip install -r requirements.txt
python main.py backtest --synthetic            # اختبار بدون إنترنت
python main.py backtest --exchange binance --symbol BTC/USDT
python main.py paper --exchange binance        # تداول وهمي ببيانات حقيقية
LIVE_TRADING=yes BINANCE_API_KEY=... BINANCE_SECRET=... python main.py live   # أموال حقيقية
pytest
```

## الأسهم الأمريكية (Alpaca)
```bash
export ALPACA_API_KEY=... ALPACA_SECRET=...
python main.py backtest --exchange alpaca --symbol AAPL --timeframe 1h
python main.py live --exchange alpaca --symbol AAPL   # حساب Alpaca التجريبي (paper) افتراضياً
LIVE_TRADING=yes python main.py live --exchange alpaca --symbol AAPL   # أموال حقيقية
```
- الدخول بأمر bracket: وقف الخسارة وجني الربح يُحفظان **على خوادم Alpaca**، فيحميان الصفقة حتى لو توقف البرنامج.
- الوقف المتحرك يُحدَّث على المنصة، والوكيل لا يتداول والسوق مغلق، والكمية أسهم صحيحة.
- أنشئ حساباً تجريبياً مجانياً من alpaca.markets للبدء.

## تحذير مهم — لا يوجد "تداول بدون خسارة"
- لا يمكن لأي وكيل ضمان عدم الخسارة. وقف الخسارة يحدّ الخسارة لكنه لا يلغيها (فجوات السعر والانزلاق تتجاوزه).
- نقل الوقف للتعادل يقلل الخسائر لكنه يقتطع أيضاً صفقات رابحة كانت ستعود للصعود.
- نتيجة الاختبار الحالية على بيانات اصطناعية عشوائية **خسارة** (لا توجد ميزة تنبؤية في بيانات عشوائية + الرسوم). هذا متوقع ويوضّح أن النموذج لا "يضمن" شيئاً.
- قبل أي مال حقيقي: اختبر على بيانات تاريخية حقيقية طويلة، ثم `paper` لأسابيع، ثم ابدأ بمبلغ صغير تتحمل خسارته.
- استخدم مفاتيح API بصلاحية التداول فقط (**بدون سحب**).
- الوقف في هذا الإصدار يُراقَب من الوكيل نفسه (ليس أمراً على المنصة)، فإذا توقف البرنامج لا يوجد وقف. للإنتاج أضف أوامر stop على المنصة.
