# bug-free-guacamole

## أداة ضغط الفيديو (`compress_video.py`)

تضغط أي فيديو ليصبح حجمه **أقل من 30MB** (أو أي حجم تحدده). تحسب الأداة معدل البت المناسب من مدة الفيديو، ثم تضغطه على مرحلتين (two-pass) بترميز H.264 ليستقر الحجم قرب الهدف.

### المتطلبات
1. **Python 3.8+** من https://www.python.org (على ويندوز فعّل خيار *Add Python to PATH* عند التثبيت).
2. **ffmpeg**. إن لم يكن مثبّتًا فالنافذة تسألك عند أول ضغط: *هل تريد تثبيته تلقائيًا؟* اضغط نعم (تحميل نحو 30MB). أو ثبّته بنفسك بإحدى الطريقتين:
   - `pip install imageio-ffmpeg` (الأسهل: يجلب ffmpeg تلقائيًا)
   - أو تثبيته يدويًا: `brew install ffmpeg` (ماك) / `sudo apt install ffmpeg` (لينكس) / `winget install ffmpeg` (ويندوز)

### الاستخدام

**بنافذة (بدون أوامر):**
```bash
python compress_video.py
```
اختر الفيديو، اكتب الحجم المطلوب (الافتراضي 30)، ثم اضغط **ابدأ الضغط**.

**من سطر الأوامر:**
```bash
python compress_video.py video.mp4                  # الناتج: video_30mb.mp4
python compress_video.py video.mp4 -t 25            # الحجم المطلوب 25MB
python compress_video.py video.mp4 -o small.mp4     # اسم ملف الناتج
python compress_video.py video.mp4 --preset slow    # أبطأ وأفضل جودة (الافتراضي: fast)
```
الفيديو الأصلي لا يتغير أبدًا، ويُحفظ الناتج بجانبه كملف جديد.

### ملاحظات
- **الجودة تعتمد على النسبة بين الحجم والمدة.** فيديو مدته 13 دقيقة في 30MB يعني نحو 290 kbps، وهذا ينتج صورة بدقة 360p وصوتًا مقتصدًا. إن أردت جودة أفضل فارفع الحجم (مثلًا `-t 60`).
- تختار الأداة دقة الصورة تلقائيًا بحسب الميزانية (360p / 480p / 720p / 1080p)، ولا تكبّر الصورة أبدًا.
- الحجم يُحسب بالميغابايت العشري (1MB = 1,000,000 بايت)، لذا يبقى الناتج تحت الحد سواء حُسب بنظام 1000 أو 1024.
- إذا كان الملف أصغر من الهدف أصلًا، أو كان الهدف أصغر من أن يعطي جودة مقبولة، تتوقف الأداة برسالة واضحة ولا تنتج ملفًا سيئًا.
