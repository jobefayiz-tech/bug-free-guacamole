# نظام بيانات الموظفين والمناديب

نظام ويب عربي لجمع بيانات الموظفين والمناديب وتحديثها باستمرار.

- **الموظف أو المندوب** يفتح رابطه الشخصي من الجوال، فيعبّئ بياناته ويرفع صور المركبة والعداد.
- **الموارد البشرية** تستورد القائمة من Excel، وتتابع من أكمل ومن لم يفتح رابطه، وتراجع وتعتمد، وتستلم تنبيهات انتهاء الهوية والإقامة والرخصة والاستمارة.

الحقول مطابقة لقالب Excel: `employee-data-template.xlsx` (يمكن تنزيله أيضًا من داخل النظام).

## نسختان من النظام

| | نسخة Python (هذا المجلد) | نسخة Google Sheets (`apps_script/`) |
|---|---|---|
| تحتاج خادمًا يعمل دائمًا | نعم | **لا** |
| التكلفة | تكلفة الاستضافة | مجانية (حساب Google عادي) |
| لوحة الموارد البشرية | صفحات ويب كاملة | الجدول نفسه (مرشحات وتلوين وقائمة) |
| إخفاء الأرقام الحساسة | نعم | لا (يراها من يفتح الجدول) |
| البيانات تُخزَّن في | خادمك | خوادم Google |
| اللغات (عربي، إنجليزي، أردو، بنغالي، هندي) | نعم | نعم |

إن لم يكن لديك خادم فابدأ من [`apps_script/README.md`](apps_script/README.md). القسم التالي يخص نسخة Python.

## التشغيل على جهاز واحد (للتجربة أو للاستخدام داخل الشركة)

يلزم Python 3.10 أو أحدث (جُرّب على 3.13).

```bash
pip install -r requirements.txt
python manage.py createuser admin --admin     # يطلب كلمة مرور (10 خانات فأكثر)
python run.py                                 # يعمل على المنفذ 8000
```

افتح `http://localhost:8000` وادخل باسم المستخدم الذي أنشأته. البيانات تُحفظ في مجلد `data/` (قاعدة بيانات وصور).

> الروابط التي سترسلها للموظفين تعمل فقط إذا كان الخادم يمكن الوصول إليه من جوالاتهم (إنترنت أو شبكة الشركة). للنشر على الإنترنت استخدم الخطوات التالية مع HTTPS.

## اللغات والجنسيات

صفحة الموظف تعمل بخمس لغات: العربية، الإنجليزية، الأردية، البنغالية، الهندية. يغيّر الموظف اللغة من أعلى الصفحة، والقيم تُخزَّن دائمًا بالعربية الموحدة فتبقى تقارير الموارد البشرية متسقة.

- **الاسم الإنجليزي هو المطلوب** (كما في الإقامة أو الجواز)، والاسم العربي اختياري.
- **جوال الطوارئ** يقبل رقمًا دوليًا (+91 / +92 / +880 ...).
- في «الروابط والتذكير» يختار النظام لغة رسالة واتساب حسب الجنسية (بنغلاديشي: البنغالية، باكستاني: الأردية، هندي: الإنجليزية، والباقي العربية)، ويمكنك فرض لغة أخرى أو التصفية بالجنسية.
- ترجمات الأردية والبنغالية والهندية في `app/i18n.py` وتحتاج مراجعة من متحدث أصلي قبل الإطلاق.

التطبيقات المتاحة للمندوب: كيتا فود، كيتا ماركت، نينجا، تويو، هنقرستيشن، مرسول (القائمة في `app/fields.py` و`tools/make_template.py`).

## الاستخدام اليومي

1. **استيراد:** من «استيراد» ارفع ملف القالب بعد تعبئته (الأعمدة المهمة: الرقم الوظيفي والاسم والجوال ورقم الهوية وبيانات الوظيفة). ابدأ بخيار «تجربة فقط» لترى الأخطاء قبل الحفظ.
2. **الروابط:** من «الروابط والتذكير» أرسل لكل موظف رابطه بزر واتساب (أو نزّل CSV). عند فتح الرابط يُطلب من الموظف آخر 4 أرقام من هويته أو إقامته أو من رقم جواله (لأن الهوية المسجلة قد تكون خاطئة).
3. **المتابعة:** لوحة «الرئيسية» تعرض من لم يفتح الرابط، ومن قيد التعبئة، ومن ينتظر المراجعة. أرسل تذكيرًا لمن تأخر.
4. **المراجعة:** افتح سجل الموظف واعتمده أو أعده له مع ملاحظة. لا يمكن اعتماد سجل فيه حقول مطلوبة ناقصة.
5. **التحديث المستمر:** الموظف يعود لرابطه نفسه متى شاء. أي تعديل بعد الاعتماد يرجع للمراجعة. «تنبيهات الانتهاء» تُظهر الوثائق المنتهية والقريبة من الانتهاء (30 / 60 / 90 يومًا).
6. **التصدير:** من «تصدير» تحصل على ملف Excel بنفس تخطيط القالب.

الأرقام الحساسة (هوية، جواز، رخصة، آيبان) تظهر مخفية، ولا تظهر كاملة إلا بزر «إظهار» الذي يُسجَّل في سجل العمليات.

## أين يعمل النظام؟

الروابط تحتاج برنامجًا يعمل دائمًا على الإنترنت. لا يوجد خيار مجاني بلا قيود، والخيارات:

| الخيار | ملاحظات |
|---|---|
| **خادم صغير مدفوع داخل السعودية** | الأكثر ثباتًا ويحقق متطلب بقاء البيانات داخل المملكة. تحقق من الأسعار الحالية عند المزوّد. |
| **Oracle Cloud Always Free** | يوجد لديهم مناطق في جدة والرياض، لكن موارد Always Free تُنشأ في المنطقة الرئيسية للحساب وحسب توفر السعة، ولم أتحقق من توفرها في المنطقتين السعوديتين. |
| **PythonAnywhere (مجاني)** | مساحة 512 MiB فقط، وتطبيق واحد، ويحتاج تمديدًا شهريًا، وخوادمه خارج السعودية. يصلح لتجربة صغيرة. |
| **Google Forms** | مجاني، لكن رفع الصور يتطلب تسجيل دخول بحساب Google، ولا يدعم رابطًا شخصيًا لكل موظف ولا مراجعة. |

## النشر على خادم بـ HTTPS (Docker + Caddy)

> ملفات Docker هنا **لم تُجرَّب** في بيئة التطوير (لم يتوفر Docker فيها). جرّبها على خادم اختبار أولًا.

1. خادم (VPS) داخل السعودية بنظام Linux، ودومين يشير إليه (سجل A).
2. ثبّت Docker، ثم:
   ```bash
   cp .env.example .env        # ضع الدومين في DOMAIN
   docker compose up -d --build
   docker compose exec app python manage.py createuser admin --admin
   ```
3. يحصل Caddy على شهادة HTTPS تلقائيًا. افتح `https://الدومين`.

## النسخ الاحتياطي

```bash
python tools/backup.py /path/to/safe/folder
```

ينتج ملف zip فيه قاعدة البيانات والصور. شغّله يوميًا (Task Scheduler في ويندوز أو cron في لينكس)، واحفظ الملف في مكان محمي لأنه يحتوي بيانات شخصية.

## الأمان

مطبّق:
- دخول الموارد البشرية بكلمة مرور مشفّرة، وقفل مؤقت بعد 5 محاولات فاشلة، وحماية CSRF، وجلسة 8 ساعات.
- رابط الموظف سري وطويل، ويتطلب آخر 4 أرقام من الهوية أو من الجوال (إن كانت الهوية مسجلة)، مع قفل بعد 5 محاولات.
- الصور تُخزَّن خارج المجلد العام ولا تُقدَّم إلا لمن سُجّل دخوله أو لصاحبها بعد التحقق. تُحذف منها بيانات الموقع (EXIF) وتُصغَّر.
- سجل عمليات لكل إضافة وتعديل واعتماد وتصدير وإظهار لرقم حساس.
- الراتب والعمولة غير موجودين في النظام عمدًا.

غير مطبّق (قرارات تخص تشغيلك):
- **تشفير الحقول الحساسة داخل قاعدة البيانات.** الحماية الحالية هي صلاحيات الملفات. فعّل تشفير القرص في الخادم وقيّد من يدخل عليه.
- **رمز تحقق عبر SMS** (يتطلب خدمة مدفوعة). البديل الحالي: رابط سري + آخر 4 أرقام.
- **التواريخ هجرية.** النظام يقبل ويعرض التواريخ ميلادية فقط. إن كانت وثائقكم هجرية فحوّلوها قبل الإدخال.

اطلب مراجعة قانونية لمتطلبات **نظام حماية البيانات الشخصية (PDPL)** قبل الاستخدام الفعلي، خصوصًا مكان الاستضافة ومدة الاحتفاظ بالبيانات.

## للمطورين

```bash
pip install -r requirements-dev.txt
python -m pytest tests
```

- `app/fields.py`: مصدر الحقول الوحيد (النموذج والتحقق والاستيراد والتصدير والإخفاء كلها تقرأ منه).
- `tools/make_template.py`: يولّد `employee-data-template.xlsx`. اختبار يتأكد أنه متطابق مع `fields.py`، فإذا أضفت حقلًا عدّل الملفين ثم أعد توليد القالب (`python tools/make_template.py`).
- المتغيرات: `DATA_DIR`، `PORT`، `BASE_URL`، `SECRET_KEY`، `HTTPS=1`، `TRUST_PROXY=1`.
